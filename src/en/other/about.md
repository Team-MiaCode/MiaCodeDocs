# About us

MiaCode is an open-source maimai chart creation tool. This site provides its user guide.

Source and releases are in the [MiaCode repository](https://github.com/Team-MiaCode/MiaCode). Documentation is maintained in [MiaCodeDocs](https://github.com/Team-MiaCode/MiaCodeDocs). Submit usage feedback to the software repository and documentation corrections to the documentation repository.
