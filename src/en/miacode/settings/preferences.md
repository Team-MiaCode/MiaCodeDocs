# Preferences

Open Preferences from the main toolbar's settings entry. Changes apply and are saved as you edit them.

## Interface

Choose Chinese, English, Japanese, or system language. Appearance supports light, dark, and system modes with corresponding palettes.

The sidebar has standard and efficient modes. Layout can place the editor before the preview or the preview before the editor. Blur materials controls the interface material effect.

## Background

Enable the MiaCode background, choose an image, and set image opacity, mask opacity, and blur radius. Scaling options include cover, contain, stretch, center, and repeat, with alignment controls.

## Editor

| Option | Purpose |
| --- | --- |
| Font size and line spacing | Adjust text density |
| Input handling | Correct full-width characters, block input methods with correction, or preserve input |
| Wrap | Display long lines within the editor width |
| Completion | Show chart-text candidates |
| Scroll past end | Provide editing space below the final line |
| Selection beat display | Show the selected passage's beat count |
| Overview ruler | Show document positions beside the editor |

## Performance

Choose hardware or software video decoding. Canvas, PV, and timeline have separate frame-rate options.

These settings control local preview. Export frame rate is configured in [Video export](/en/miacode/export/video).

## Shortcuts

Select a command row and press a new key combination. `Esc` cancels capture. The row's reset button restores its default binding.

Menu shortcut labels update with your preferences.

## Updates

Choose the stable or prerelease channel and whether to check at startup. Use Check now to read the selected channel's update status.
