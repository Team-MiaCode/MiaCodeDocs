# Interface modes

Choose Standard or Classic (1.x) under `Preferences → Interface → Navigation mode`.

## Standard mode

The activity bar provides entries for charts, export, network, tools, and preferences. The adjacent sidebar shows the selected group. The chart group contains difficulties and bookmarks. Click the network icon to open the [chart download and upload](/en/miacode/tools/download) menu.

## Classic mode {#efficient-mode}

In Classic (1.x) mode, one sidebar contains chart information, latency calibration, difficulties, bookmarks, export, and tools. Use the arrow on its right edge to collapse or expand it. Open chart download and upload from the Network menu at the top.

## Layout and scale

Select the editor and preview order under `Preferences → Interface → Layout`. Drag panel boundaries to resize them. Toolbar buttons toggle the sidebar and bottom panel.

Use `Ctrl/⌘+Alt/⌥+=`, `Ctrl/⌘+Alt/⌥+-`, and `Ctrl/⌘+Alt/⌥+0` to enlarge, reduce, and reset interface scale. Set the editor font size under `Preferences → Editor`.

The preview can [detach into a separate window](/en/miacode/chart/preview#detach-and-dock).
