# Interface modes

Choose Standard or Efficient under `Preferences → Interface → Sidebar mode`.

## Standard mode

The activity bar switches between charts, export, tools, and preferences. The adjacent sidebar shows the selected group. The chart group contains difficulties and bookmarks.

## Efficient mode

One sidebar contains chart information, latency calibration, difficulties, bookmarks, export, and tools. Use the arrow on its right edge to collapse or expand it.

## Layout and scale

Select the editor and preview order under `Preferences → Interface → Layout`. Drag panel boundaries to resize them. Toolbar buttons toggle the sidebar and bottom panel.

Use `Ctrl/⌘+Alt/⌥+=`, `Ctrl/⌘+Alt/⌥+-`, and `Ctrl/⌘+Alt/⌥+0` to enlarge, reduce, and reset interface scale. Set the editor font size under `Preferences → Editor`.

The preview can [detach into a separate window](/en/miacode/chart/preview#detach-and-dock).
