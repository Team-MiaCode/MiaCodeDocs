# Cover export

Open `Export → Cover export` to compose a publishing cover from song information, images, text, and chart frames.

## Canvas and background

Choose a canvas preset with a 1:1, 4:3, or 16:9 aspect ratio. Use the jacket, a custom image, or transparency for the background, and adjust brightness or blur.

## Layers

Add chart-frame, image, or text layers. The layer list supports reordering, duplication, deletion, visibility, and locking.

Select a layer to change its position, size, and opacity. Text layers support content, color, bold, and fonts. Image layers use a selected image file.

## Chart frames

Add a chart-frame layer, choose a difficulty, and seek to the moment to display. Play or scrub to inspect the pattern.

Inner and outer background options include transparency, images, and PV, allowing chart patterns to be composed with other cover elements.

## Layouts and presets

Save layout writes the composition to a file for later editing. Save preset stores a reusable layout style for other songs.

## Export

Choose the output path and size, then export. Supported formats include PNG, JPG, JPEG, and BMP. Choose PNG for transparency.
