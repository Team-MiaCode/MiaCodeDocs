# Package ZIP

Use `Export → Package ZIP` to package a chart and its media for sharing or uploading.

Choose an output location. The archive uses the current workspace's chart text, including changes across difficulties.

## Included files

The archive contains chart text and the resolved song audio, jacket, and PV located beside the chart. Common names are `maidata.txt`, `track.mp3`, `bg.jpg`, and `pv.mp4`; assets retain their actual filenames.

Place media to be shared in the chart folder and confirm its references in [Chart information](/en/miacode/chart/information).

Autosave snapshots and media `_bak` files are local recovery material. Copy the chart folder together with its `.miacode` directory when preserving this material.
