# Package ZIP

Use `Export → Package ZIP` to package a chart and its media.

Choose an output location. The archive uses the current workspace's chart text, including changes across difficulties.

## Included files

The archive contains chart text and the resolved song audio, jacket, and PV located beside the chart. Common names are `maidata.txt`, `track.mp3`, `bg.jpg`, and `pv.mp4`; assets retain their actual filenames.

PV uses video in the chart folder. Its reference path is set in [Chart information](/en/miacode/chart/information).

Autosave snapshots and media `_bak` files are local recovery material, covered in [Backup & recovery](/en/miacode/backup-recovery).
