# Intro

Enable the intro on the video export page.

## Style and background

Choose Classic or PV preview style. Use the jacket or a custom image as the background, with blur and difficulty-card shadow options.

Chart type supports automatic selection, DX, and SD. Choose how the level is rendered, and set the title and body fonts separately.

## PV segment and audition

For PV preview style, set the segment start with the range control. Audition plays the selected PV segment.

With the range control focused, press Left or Right to move the segment start backward or forward by 0.1 seconds. Hold `Shift` with an arrow key to move it by 1 second.

The start is saved for the chart and shared by its difficulties. Batch items use the start stored for their own chart.

## Information and sound

Title, level, and designer come from [Chart information](/en/miacode/chart/information). Fonts can be selected from the library or imported.

The Export intro channel in [Audio settings](/en/miacode/settings/audio) controls intro sound level.
