# Syntax & pattern warnings

The bottom panel provides separate syntax and pattern analysis lists. Editing the current difficulty updates its results.

## Syntax

Syntax checks identify simai parsing errors and warnings. Review each message and its location, then select an entry to navigate to the corresponding line, column, and preview time.

Resolve parsing errors so the timeline, preview, and export can use valid chart data.

## Pattern warnings

Muri analyzes patterns for playability risks recognized by its rules. Select an entry and inspect note order, placement, and overlap in the preview.

Use the results alongside your own assessment of hand movements and actual playability.
