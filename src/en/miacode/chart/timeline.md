# Timeline

The bottom timeline displays the song waveform and chart notes. Use it to locate passages and compare the beat with the preview.

## Seeking and zoom

Drag the timeline to move the playback position and update the preview. Increase zoom to inspect dense patterns; reduce it to browse a longer passage.

Zoom changes how much time fits within the visible width. Playback speed is controlled from the preview toolbar.

## Bottom panel

Switch between the timeline, syntax checks, and pattern warnings. Analysis entries provide navigation to the corresponding chart location; see [Syntax & pattern warnings](/en/miacode/chart/validation).

The timeline frame rate is set in [Preferences → Performance](/en/miacode/settings/preferences#performance).
