# Chart organization

Use `Tools → Chart organization` or `Transform → Chart organization` to organize chart text. The editor context menu also provides this command. The dialog shows the scope being processed. Review that scope, choose options, and apply.

## Options

| Option | Purpose |
| --- | --- |
| Align to 1/384 measure | Organize timing on a 1/384-measure grid |
| Blank-line grouping | Group every 2 or 4 measures, or arrange continuously |
| Output format | Preserve segments or use compact format |

Preserve segments keeps the passage structure; compact format concentrates the text. Choose the form that fits your editing workflow. The default selections suit most cases.
