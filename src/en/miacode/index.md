# Introduction

MiaCode is an open-source maimai chart creation tool. It combines text editing, live preview, timeline navigation, syntax and pattern checks, and video and cover export in one workspace. This manual covers the 2.0.0-alpha interface and features.

## Features

- [Text editor](/en/miacode/chart/text-editor): writes simai text with completion, selection beats, and selection tools.
- [Chart preview](/en/miacode/chart/preview): displays notes, backgrounds, and PV, with playback and seeking controls.
- [Timeline](/en/miacode/chart/timeline): displays the waveform, beat grid, and notes, with seeking, dragging, and zoom controls.
- [Chart organization](/en/miacode/tools/chart-organization): formats subdivisions, line breaks, and spacing.
- [Syntax & pattern warnings](/en/miacode/chart/validation): lists syntax errors, compatibility warnings, and pattern results for the current difficulty.
- [Video export](/en/miacode/export/video): supports full-song, range, and batch export.

The sidebar switches between charts, export, settings, and tools. The main area holds the editor and preview; the bottom panel provides the timeline, syntax checks, and pattern checks. Drag panel boundaries to resize them, and configure the editor/preview arrangement in [Preferences](/en/miacode/settings/preferences#interface-and-layout).
