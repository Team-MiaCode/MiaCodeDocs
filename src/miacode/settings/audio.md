# 音频设置

使用 `预览 → 音频设置` 调整预览与片头音效。拖动滑块设置音量，双击百分比可以输入数值，点击扬声器图标切换静音。

## 声音通道

| 通道 | 控制的声音 |
| --- | --- |
| 全局音量 | 所有预览声音的整体音量 |
| 曲目 | 歌曲音频 |
| 正解音 | 表示节拍的正解音 |
| Tap、EX、Break | 对应物件的音效 |
| Break Slide、Slide | Slide 音效 |
| Touch、Hanabi | Touch 与烟花音效 |
| 导出片头 | 片头音效 |

修改带试听音的通道后，窗口会播放对应音效。`静音 Break 星星尾判音` 控制 Break Slide 尾部判定声音。

## 本地默认值

音量调整应用于当前谱面。`设为本地默认` 保存本机默认值，`恢复本地默认` 将默认值应用到当前谱面。BPM 与偏移在[延迟校准](/miacode/chart/latency-calibration)中调整。
