# 音频设置

使用 `预览 → 音频设置` 打开混音窗口。拖动滑块调整音量，双击百分比输入数值，点击扬声器图标切换该通道的静音状态。

## 声音通道

| 通道 | 控制的声音 |
| --- | --- |
| 全局音量 | 混音的整体音量 |
| 曲目 | 歌曲音频 |
| 正解音 | 表示节拍的正解音 |
| Tap、EX、Break | 对应物件的音效 |
| Break Slide、Slide | 对应 Slide 音效 |
| Touch、Hanabi | Touch 与烟花音效 |
| 导出片头 | 片头音效 |

修改有试听音的通道后，窗口会播放对应音效，便于判断音量。曲目音量可结合预览播放调整。

`静音 Break 星星尾判音` 用于控制 Break Slide 尾部的判定声音。

## 本地默认值

音量调整会应用到当前谱面。选择 `设为本地默认` 将当前混音保存为本机的默认设置；选择 `恢复本地默认` 将该默认值应用到当前谱面。

BPM 与谱面时间偏移在 [延迟校准](/miacode/chart/latency-calibration) 中调整。
