# 首选项

点击主工具栏的设置入口打开 `首选项`，选项修改后生效并保存。

## 编辑器

设置字号、行距、自动换行、补全与编辑辅助，调整谱面文本的输入和阅读体验。

## 自动补全

开启 `自动补全` 后会自动展开 `自定义候选`，可以分别管理时值和节拍分音。填写时值 `4:1`、分音 `16` 等候选内容，括号由补全操作添加。BPM 候选由整曲 BPM 与当前难度文本生成。

在列表末尾输入候选，按 `Enter` 或离开输入框保存；拖动候选调整顺序，也可删除候选。`恢复默认` 会恢复该组的默认候选，按确认窗口选择。

时值使用合法时值格式，支持变 BPM 符号 `#`；节拍细分填写正整数。全角符号会转换为半角符号，格式校验通过后保存。

## 概览标尺

概览标尺的初始状态为关闭，在 `首选项 → 编辑器` 中开启 `概览标尺`。标尺位于编辑器右侧滚动条旁：黄色标记警告，蓝色标记书签，红色标记错误或无理检测结果，横向标记表示光标或跟随位置。

## 快捷键

选择命令所在行，输入组合键；`Esc` 取消录入。行内重置恢复该命令的默认值，`恢复全部默认` 恢复整组快捷键。播放速度与时间轴缩放也可在这里调整，菜单中的快捷键随设置变化。

### 默认快捷键

下表列出首选项中各命令的默认组合键，同一行的功能与快捷键按顺序对应。`⌘` 表示 Command，`⌥` 表示 Option；`Ctrl/⌘++` 末尾的 `+` 表示加号键。

| 功能 | 快捷键 |
| --- | --- |
| 左右 / 上下镜像 | `Ctrl/⌘+J` / `Ctrl/⌘+K` |
| 旋转 180° | `Ctrl/⌘+L` |
| 逆时针 / 顺时针旋转 45° | `Ctrl/⌘+;` / `Ctrl/⌘+'` |
| 分音提升一 / 半档 | `Ctrl/⌘+=` / `Ctrl/⌘++` |
| 分音降低一 / 半档 | `Ctrl/⌘+-` / `Ctrl/⌘+Shift+-` |
| 一键全 Break / Ex / Firework / 随机 | `Ctrl/⌘+B` / `Ctrl/⌘+N` / `Ctrl/⌘+M` / `Ctrl/⌘+,` |
| 停止或播放预览（停止时返回本次播放的起点） | `Ctrl/⌘+Shift+C` |
| 播放 / 暂停预览 | `Ctrl/⌘+Shift+X` |
| 播放速度降低 / 提高 | `Ctrl/⌘+O` / `Ctrl/⌘+P` |
| 暂停时切换判定区 / PV（按住） | `Alt/⌥` |
| 时间轴放大 / 缩小 | `Ctrl/⌘` + 向上 / 向下滚轮 |
| 编辑器字号减小 / 增大 | `Ctrl/⌘+Alt/⌥+-` / `Ctrl/⌘+Alt/⌥+=` |
| 覆写模式（输入时替换光标后的字符） | `Insert` |

### 文件与编辑按键

文件菜单和编辑器使用以下组合键。

| 功能 | 快捷键 |
| --- | --- |
| 新建谱面 | `Ctrl/⌘+Shift+N` |
| 打开谱面 | `Ctrl/⌘+Shift+O` |
| 保存当前编辑部分 | `Ctrl/⌘+S` |
| 另存为 | `Ctrl/⌘+Shift+S` |
| 关闭当前编辑页或独立窗口 | `Ctrl/⌘+W` |
| 撤销 | `Ctrl/⌘+Z` |
| 重做 | `Ctrl+Y` / `⌘+Shift+Z` |
| 剪切 / 复制 / 粘贴 | `Ctrl/⌘+X` / `Ctrl/⌘+C` / `Ctrl/⌘+V` |
| 全选 | `Ctrl/⌘+A` |
| 查找与替换 | `Ctrl/⌘+F` |
| 打开编辑器右键菜单 | `Shift+F10` 或菜单键 |
| 选择补全候选 | 上、下方向键 |
| 接受补全候选 | `Enter/Return` 或 `Tab` |
| 关闭补全或查找面板 | `Esc` |
| 查找下一项 / 上一项 | 查找框中的 `Enter/Return` / `Shift` + `Enter/Return` |
| 替换当前匹配项 | 替换框中的 `Enter/Return` |
| 重命名 / 删除书签 | 书签条目上的 `F2` / `Delete` 或 `fn+Delete` |

## 界面与布局

选择语言、浅色或深色主题及配色。`导航模式` 提供 `标准` 与 `经典（1.x）`；布局选择 `编辑器｜预览` 或 `预览｜编辑器`，控制两个面板的左右位置。模糊材质控制界面材质效果。

## 性能

视频解码可选择硬件或软件方式，画布、PV 与时间轴分别设置刷新率。视频输出帧率见[视频导出](/miacode/export/video#输出参数)。

## 背景

开启 MiaCode 背景后选择图片，调整图片透明度、遮罩与模糊。覆盖、完整显示、拉伸、居中和平铺控制图片布局，位置选项控制对齐。

应用背景用于软件界面；谱面背景与 PV 的画面效果见[预览设置](/miacode/settings/preview#视频)。

## 更新

选择正式版或预发布版通道，设置启动时检查更新，或使用 `立即检查` 查看所选通道的结果。
