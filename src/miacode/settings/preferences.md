# 首选项

点击主工具栏的设置入口打开 `首选项`。这里管理本机的界面、编辑器、性能、快捷键和更新选项，修改选项后生效并保存。

## 界面

选择简体中文、English、日本語或跟随系统。外观模式支持浅色、深色与跟随系统，并可设置对应的配色。

侧栏提供标准与高效模式。界面布局可以选择“编辑器｜预览”或“预览｜编辑器”，调整两个面板的排列方向。模糊材质开关用于调整界面材质效果。

## 背景

开启 MiaCode 背景后，选择图片并设置图片透明度、遮罩透明度和模糊半径。缩放模式提供覆盖、完整显示、拉伸、居中和平铺，位置选项用于控制图片对齐。

## 编辑器

| 选项 | 用途 |
| --- | --- |
| 字号、行距 | 调整文本的显示密度 |
| 输入法与字符更正 | 选择全角字符更正、关闭输入法并更正字符，或保留原始输入 |
| 自动换行 | 按编辑器宽度显示长行 |
| 自动补全 | 显示谱面文本的补全候选 |
| 允许滚动到末行顶部 | 为末尾段落提供编辑空间 |
| 显示选区拍数 | 查看所选谱面段落的拍数 |
| 概览标尺 | 在编辑器侧边显示文本位置概览 |

### 自动补全

::: tip
自定义时值或节拍细分时，无需填写 `[]` 或 `{}`。
:::

MiaCode 提供时值与节拍细分的补全候选，选择候选项可以完成输入。开启 `自动补全` 后，可以展开 `自定义候选`。

在列表末尾输入内容可添加候选；按 `Enter` 或离开输入框后保存。候选项可以删除或拖动排序，点击 `恢复默认` 并确认后恢复默认候选。

时值需填写合法的时值格式，也支持变 BPM 符号 `#`。节拍细分允许填写正整数。输入符号时，MiaCode 会将全角符号自动转换为半角符号。保存填写内容时，MiaCode 会进行合法性校验，不会保存格式不合法的内容。

## 性能

视频解码可选择硬件或软件解码。画布、PV 与时间轴分别有刷新率选项，可按设备和显示需求调整。

这些选项控制本地预览的显示，导出视频的帧率在 [视频导出](/miacode/export/video) 中设置。

## 快捷键

点击命令所在行，按下要使用的组合键；`Esc` 取消本次录入。每个命令旁的重置按钮恢复该命令的默认快捷键。

菜单中显示的快捷键会随设置更新，编写谱面时可以按自己的操作习惯调整。

## 更新

选择正式版或预发布版更新通道，设置启动时检查更新。点击 `立即检查` 查看所选通道的更新结果。
