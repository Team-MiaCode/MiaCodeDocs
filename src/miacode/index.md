# 简介

MiaCode 是用于创作 maimai 谱面的开源工具，将文字编辑、实时预览、时间轴、语法与无理检测、视频和封面导出放在同一个工作区中。本手册对应 2.0.0-alpha 的界面与功能。

## 功能

- [文字编辑](/miacode/chart/text-editor)：编写 simai 文本，支持自动补全、选区拍数与选区调整。
- [谱面预览](/miacode/chart/preview)：显示物件、背景与 PV，提供播放和定位控制。
- [时间轴](/miacode/chart/timeline)：显示波形、节拍线与物件，支持定位、拖动和缩放。
- [谱面整理](/miacode/tools/chart-organization)：调整分音表示、换行与段落间距。
- [语法与无理检测](/miacode/chart/validation)：列出当前难度的语法错误、兼容性警告和无理检测结果。
- [视频导出](/miacode/export/video)：支持整曲、区间与批量导出。

左侧栏切换谱面、导出、设置和工具，主区域放置编辑器与预览，底部面板提供时间轴、语法检查和无理检测。面板边界可以拖动，编辑器与预览的左右位置在[首选项](/miacode/settings/preferences#界面与布局)中设置。
