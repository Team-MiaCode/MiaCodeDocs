# 谱面整理

谱面整理调整分音表示、换行和段落间距。使用 `工具 → 谱面整理`、`调整 → 谱面整理` 或编辑器右键菜单打开整理窗口。

## 处理范围

处理范围默认为当前难度的全部文本；选择片段后，整理范围为所选文本。窗口会显示整份谱面或选区的起止行。设置格式后点击 `整理`，结果写回编辑器。

整理会读取选区前的 BPM 和分音，并按新小节起点排版所选片段。解析错误会显示在窗口中，错误位置与含义见[语法检查](/miacode/chart/validation#语法)。

## 整理前后

以下示例展示整理前后的文本变化。

```text
{32}5,4,3,2,8,7,6,5,{16}3,3,4,4,5,4,3,2,8,7,6,5,
```

使用 `保留分段` 格式并开启 `对齐至 1/384 小节`，整理结果为：

```text
{32}5,4,3,2,8,7,6,5, {16}3,3,4,4, 5,4,3,2, 8,7,6,5,
```

每拍之间加入空格，一小节占一行，该片段的物件与节拍位置保留。

## 整理选项

| 选项 | 作用 |
| --- | --- |
| 对齐至 1/384 小节 | 开启后按 1/384 小节网格整理时间与时值；关闭后保留超出该网格的精度 |
| 空行分组 | 选择每 2 小节、每 4 小节加入空行，或连续排列 |
| 输出格式 | 保留分段在每拍之间加入空格；紧凑格式按小节集中排列文本 |

初始选项为对齐至 1/384 小节、每 4 小节分组和保留分段。窗口会记住应用的选项。
