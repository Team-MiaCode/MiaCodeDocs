# 谱面下载

使用 `工具 → 谱面下载` 查询服务器中的谱面，并下载到本地。

## 查询

填写用户 ID、标签或歌曲名，选择日期范围与排序方式后点击 `查询`。结果列表显示歌曲和上传信息，可选择要下载的谱面。

使用区分大小写或模糊匹配选项调整查询，`从服务器刷新` 用于获取服务器中的结果。`检测连接` 显示连接状态。

## 下载与预览

选择目标文件夹，勾选谱面。按需要选择下载 PV，或在成功后额外生成 ZIP，然后点击下载所选谱面。

结果列表提供谱面预览入口，便于在下载前查看配置。任务进度与日志显示处理状态；暂停状态下通过 `继续下载` 恢复任务。

需要向服务器发布本地谱面时，使用 [谱面上传](/miacode/tools/upload)。
