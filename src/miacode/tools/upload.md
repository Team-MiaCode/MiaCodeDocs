# 谱面上传

使用 `工具 → 谱面上传` 将本地谱面加入上传队列并发布到服务器。

## 准备队列

选择谱面根目录，点击 `添加到队列`。检查列表中的谱面文件夹、文件、路径和状态，通过上移、下移调整顺序，或移除所选条目。

上传前在 [谱面信息](/miacode/chart/information) 中确认标题、谱师、等级与素材，并用 [检测列表](/miacode/chart/validation) 查看谱面。

## 上传结果

开始上传后就可以查看进度与日志了。任务结束时将会显示成功、失败和待确认的数量。

条目显示“服务器结果待确认”时，需要自行确认上传结果。

获取服务器中的谱面见 [谱面下载](/miacode/tools/download)。
