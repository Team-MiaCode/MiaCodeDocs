# 界面模式

在 `首选项 → 界面 → 导航模式` 选择 `标准` 或 `经典（1.x）`。

## 标准模式

活动栏提供谱面、导出、网络、工具和首选项入口；旁边的侧栏显示当前分组的功能。谱面分组中可以添加难度、切换难度和跳转书签。点击网络图标可打开[谱面下载与上传](/miacode/tools/download)菜单。

## 经典模式 {#高效模式}

经典（1.x）模式的侧栏集中显示谱面信息、延迟校准、难度、书签、导出和工具入口。点击侧栏右侧的箭头收起或展开侧栏。谱面下载与上传通过顶部 `网络` 菜单打开。

## 布局与缩放

在 `首选项 → 界面 → 布局` 选择编辑器与预览的左右顺序。拖动面板边界调整宽度与底部面板高度；主工具栏的侧栏、底部面板按钮控制对应区域的显示。

`Ctrl/⌘+Alt/⌥+=` 放大界面，`Ctrl/⌘+Alt/⌥+-` 缩小界面，`Ctrl/⌘+Alt/⌥+0` 恢复默认比例。编辑器字号在 `首选项 → 编辑器` 设置。

预览可以[分离为独立窗口](/miacode/chart/preview#分离与停靠)。
