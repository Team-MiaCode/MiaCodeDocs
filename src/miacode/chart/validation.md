# 语法与无理检测

底部面板的 `语法` 和 `无理` 标签显示当前难度的检测结果。编辑谱面文本后，列表会更新；点击条目会定位到对应行、列和预览时间。

## 语法

语法检查解析 simai 文本，列出语法错误与兼容性警告。点击 `重新检查` 可更新检测结果。

### 检测规则

| 检查内容 | 规则 |
| --- | --- |
| BPM 与分音 | BPM 为有效的正数，分音为正整数；BPM 指令后的物件应有明确的分音 |
| 括号 | `()`、`{}`、`[]` 和 `<HS*>` 需要成对闭合 |
| 时间分隔 | 逗号推进时间；行尾物件、物件与 BPM 或分音指令之间的逗号缺失时会产生提示 |
| 多押分隔 | `/` 与反引号两侧需要物件；连续的 `//` 会报错 |
| Hold 与 Touch | 检查时值、区域编号和修饰符；带时值的 Touch 使用 `h`，中心 Touch 使用 `C` |
| Slide | 检查路径、段链、时值块和修饰符位置；同头分支 `*` 后省略起点编号 |
| 字符与结束标记 | 检查全角数字、括号、分隔符等字符，以及结束标记 `E` 的位置 |

兼容性警告包括：分音超过 384 或无法整除 384、短 Hold 的 `h` 位置、Hold 和 Break Slide 的修饰符顺序，以及 Slide 时值块的位置。警告表示该写法可能影响其他 simai 软件的解析或转谱。

## 无理

### 检测规则

| 类型 | 检测内容 |
| --- | --- |
| 内无 | Slide 或 Wifi 的完成时间提前，或超出其判定时间范围 |
| 外无 | Slide 启动或偷跑时，起点的按下动作提前判定后续物件 |
| 撞尾 | Slide 或 Wifi 经过的判定区域与其他物件发生时间冲突 |
| 叠键 | 相同位置的物件判定重叠，或物件受已有按下、长按影响而错过判定时间 |
| 多押 | 同一时刻的手部动作需要超过两只手 |

结果分为 `无理` 与 `警告`。部分时间边界情况会列为警告；带 EX 保护的普通物件，其相关提示也会降为警告。

预览的 `无理检测` 渲染模式提供手掌半径与 Slide 路径上 Tap 的时间阈值。手掌半径控制模拟手部的覆盖范围；时间阈值控制相关时间冲突的静态检查范围，默认 200 ms，可设为 150–250 ms。
