# 延迟校准

延迟校准用于确定歌曲的 BPM 与谱面偏移，并通过计拍试听检查节拍。入口为 `谱面 → 延迟校准` 或 `工具 → 延迟校准`。

## BPM 与偏移

已知 BPM 时填写数值；需要估算时，点击 BPM 旁的 `自动检测`。软件读取当前歌曲并显示检测结果，采用的数值会写入谱面。

确定 BPM 后，点击偏移旁的 `自动检测`。偏移以秒为单位，对应谱面信息中的 `&first`。BPM 决定节拍间隔，偏移决定谱面与歌曲的时间对应关系。

## 试听

设置计数拍与细分，点击 `开始试听`，对照歌曲重拍与计拍音。音效音量用于调整试听时的计拍声音。

检测值适合作为校准起点。若节拍在整段歌曲中逐渐偏离，检查 BPM；若始终保持相近的时间差，调整偏移。变速歌曲的各段 BPM 需要在谱面文本中设置。

## 文件处理与谱面偏移

调整偏移会改变谱面与歌曲的对应关系。需要给音频或 PV 添加开头空白时，使用 [媒体工具](/miacode/tools/media#前置空白)，处理后通过试听确认对齐。
