# 封面导出

使用 `导出 → 封面导出` 制作投稿封面。封面编辑器提供画布、图层与谱面帧选项，可组合歌曲信息、图片、文字和配置画面。

## 画布与背景

选择输出大小，支持 1:1、4:3 和 16:9 比例的预设。背景可使用曲绘、自定义图片或透明背景，并调整亮度与模糊效果。

## 图层

通过 `添加图层` 添加谱面帧、图片或文字。图层列表可调整上下顺序、复制、删除、显示和锁定状态。

选择图层后修改位置、大小和透明度。文字图层可填写文字并设置颜色、粗体与字体；图片图层可选择图片文件。

## 谱面帧

添加谱面帧图层后，选择难度并定位到需要展示的时间。播放或拖动时间控件，确认该帧的配置。

谱面帧可选择内侧、外侧的背景表现，包括透明、图片与 PV 等选项，适合在封面中叠加配置画面。

## 布局与预设

`保存布局` 将封面布局写入文件，便于打开后继续编辑。`保存预设` 保存可复用的布局样式，制作其他歌曲的封面时可以应用。

## 导出图片

选择输出路径与大小，点击 `导出`。图片格式支持 PNG、JPG、JPEG 和 BMP；需要保留透明背景时选择 PNG。
