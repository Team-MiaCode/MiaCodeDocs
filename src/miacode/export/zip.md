# 打包 ZIP

使用 `导出 → 打包 ZIP` 将谱面文档和素材打包，便于传递给其他用户或上传。

选择输出位置后生成压缩包。谱面文档使用当前工作区中的内容，包含各难度的修改。

## 包含的文件

压缩包包含谱面文本，以及当前谱面解析到的同目录歌曲音频、曲绘和 PV。常见文件为 `maidata.txt`、`track.mp3`、`bg.jpg` 和 `pv.mp4`；素材文件按实际文件名打包。

PV 使用谱面目录中的视频。准备发布时，将要随谱面传递的素材放在同一目录，并在 [谱面信息](/miacode/chart/information) 中确认引用。

自动保存快照和媒体处理生成的 `_bak` 备份属于本地恢复资料。需要保留这些资料时，复制谱面文件夹及其 `.miacode` 目录。
